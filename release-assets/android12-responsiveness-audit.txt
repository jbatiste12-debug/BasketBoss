Outcome and remaining limit
The candidate removes duplicated main-thread work and retains the existing business rules and safety owners. Warm Plan, At home and Feeding transitions improve materially in the controlled simulation. It does not establish instant responsiveness. The first navigation RAF is slightly slower at1x and regresses from10,983ms to12,566ms at4x; a6,142ms startup task remains before that frame. A physical Galaxy A13 installation is still required. This build is not being represented as a complete fix for every loading delay.

Root causes and targeted changes
1. Quantity readouts constructed an Intl.NumberFormat for each displayed amount. Two immutable locale-specific formatters are reused. Every current input, unit conversion, market, precision and tiny-positive display rule still runs unchanged.
2. A retired budget meter continued recalculating the canonical weekly summary although current Plan/At home presentation already hid it. Only that retired renderer is skipped when its exact current owner exists. Missing owners retain the original fallback and save/error behavior. The real weekly summary is neither rewritten nor cached.
3. One pantry presentation refresh rebuilt the same live descriptors repeatedly. A read-only array is passed only within that valid synchronous paint. Later actions, external changes, editor conflicts and actor/deletion guards still read their live owners.
4. Native details notifications repeated descriptor work after their storage/open/visible/navigation markers were already painted. Only identical settled presentation notifications skip that redundant work. Real closes, mismatches and missing markers keep the original live update.
5. Closed Plan disclosures forced card geometry on unrelated mutations. Their closed decoration pass no longer measures layout; actual opening and existing resize/scroll/focus/Escape/outside-click behavior remain.
6. The Shop stock banner measured hidden or missing targets on other tabs. Inactive views skip those geometry reads; active-Shop state, actor/session handling, deletion locks and requirement ownership remain.
7. Non-US text painting eagerly computed US name/unit conversions that it discarded. Only the selected original display expression is evaluated. Market switching, live source text, pricing controls, offers and stored data remain unchanged.
8. Ingredient strings repeatedly traversed identical Unicode/case/dash/whitespace cleanup expressions. Three private helpers now retain only primitive normalization strings, limited to512 entries and256 UTF-16 input units. Pricing still performs String(s||'') on every call; pantry/household retain their original nonstring guards. Long inputs bypass retention. No canonical identity, callback, final match, price, quantity, plan, account, entitlement or safety result is cached.
9. The dominant remaining delay is original synchronous rendering and live shopping/pantry matching, including the required receipt-host render during startup. Desktop real-touch traces show little input-to-click hesitation compared with handler-to-frame delay. No extra touch/CSS/routing rewrite was added to mask this work.
